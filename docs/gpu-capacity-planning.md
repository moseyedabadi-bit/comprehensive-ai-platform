# ظرفیت‌سنجی GPU

برآورد ظرفیت باید بر مبنای **اندازه مدل، دقت محاسبات، طول متن، تعداد درخواست هم‌زمان، نرخ توکن و SLA** باشد؛ تعداد کاربران یا شعب به‌تنهایی مبنای کافی نیست.

## روش آزمایش
1. انتخاب مجموعه تست نماینده از درخواست‌های واقعی اما بی‌نام‌سازی‌شده
2. اندازه‌گیری تأخیر تا نخستین توکن (TTFT) و توکن بر ثانیه
3. آزمون بار افزایشی و تعیین نقطه اشباع
4. ثبت مصرف GPU، VRAM، RAM، CPU و شبکه
5. لحاظ کردن افزونگی و زمان توقف سرویس

## خروجی مورد انتظار
جدول ظرفیت سرویس به ازای هر مدل و تنظیم، هزینه هر هزار درخواست و شرایط مقیاس‌پذیری. عدد قطعی تا پیش از Benchmark ارائه نمی‌شود.

# امنیت و حاکمیت

- احراز هویت متمرکز و RBAC/ABAC در لایه ابزار و داده
- ثبت Audit Trail بدون ذخیره غیرضروری داده حساس
- نگهداری اسرار در Secret Manager و جلوگیری از ثبت در Git
- مقابله با Prompt Injection و محدودسازی فراخوانی ابزار
- سیاست حذف داده، حداقل‌سازی داده و بازبینی مجوزها
- کنترل انسانی برای اقدامات تغییردهنده در سامانه‌های عملیاتی
- ارزیابی حقوقی پیش از انتشار کد، نمودار یا داده با منشأ سازمانی
